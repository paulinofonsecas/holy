# Quick Start Draft

## Prerequisites
- Flutter SDK (^3.6.0)
- Dart SDK
- Git
- VS Code (Recommended)
- **Windows**: Visual Studio 2022 (with C++ Desktop development)
- **macOS**: Xcode, CocoaPods

## 3-Step Setup

1. **Clone & Environment**
   ```bash
   git clone https://github.com/paulinofonsecas/holy.git
   cd holy
   cp .env.example .env # Fill in with your credentials
   ```

2. **Install Dependencies**
   ```bash
   flutter pub get
   cd packages/bible_handler
   flutter pub get
   cd ../..
   ```

3. **Run Application**
   ```bash
   flutter run
   ```
