# Quickstart: Reorder Search Inputs

## Setup
1. Launch the app and navigate to the **Search** screen.
2. Add at least two search terms using the "Adicionar termo" button.

## Verification Steps
1. **Drag to Reorder**: 
   - Observe the drag handle icon on the left side of each search box.
   - Press and hold the handle of the second search box and drag it above the first one.
   - Release the box.
2. **Observe results**:
   - Verify that the boxes have swapped positions.
   - Verify that the label of the first box remains "Buscar por..." and the second box becomes "E também por...".
   - If terms were entered, verify that search results are refreshed.
3. **Data Integrity**:
   - Type specific text in each box (e.g., box 1: "Deus", box 2: "Amor").
   - Reorder them.
   - Verify "Deus" is now in the second box and "Amor" is in the first, without any lost characters.
