# Notas de Versão - Holy 1.0.1+20

## O que há de novo?

### 🎨 Criador de Imagens 2.0
- Compartilhe textos longos sem preocupação! O app agora divide automaticamente versículos extensos em várias imagens scroláveis, mantendo o design perfeito.
- Novo sistema de ajuste inteligente: o texto agora se adapta automaticamente para nunca sair das bordas do card.

### 🔍 Busca Facilitada
- Adicionamos uma barra de pesquisa na lista de livros. Ficou muito mais rápido encontrar o livro que você deseja, mesmo digitando sem acentos.

### 💅 Interface e Experiência
- Navegação entre livros agora é uma página dedicada, muito mais rápida e elegante.
- Novo sistema de notificações (Toasts) para confirmar ações como "Copiado com sucesso".
- Inicialização ultra-rápida: removemos aquelas "piscadinhas" de carregamento ao abrir o app.

### 🛠️ Estabilidade
- Corrigimos bugs nas notificações do "Versículo do Dia" em alguns dispositivos Android.
- Melhorias internas de performance para garantir que o app rode suave mesmo em aparelhos mais simples.
